# Workspace Rules

## Terminology
- **Strictly use "staf" instead of "staf":** When referring to subordinates or team members in UI labels, documentation, and source code variables, always use "staf" instead of "staf". "Staf" is considered unpolished in this corporate environment. 
  - UI labels: "Penilaian Staf", "Daftar Staf", "Staf Saya".
  - Code variables: `$stafIdTerpilih` instead of `$staf_id_terpilih`, `getStaf()` instead of `getStaf()`.

## Application Naming
- **Strictly use "Evidence Command Center (ECC)"**: The official application name is **Evidence Command Center (ECC)** (or **ECC**). "Simonik" is the legacy application name (even though the root folder name is `SimonikPKTJ`). Always use **Evidence Command Center (ECC)** or **ECC** across all UI labels, page titles, headers, footers, system logs, documentation, and responses instead of "Simonik".
